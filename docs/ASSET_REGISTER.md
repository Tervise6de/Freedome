# Asset register

Every asset in this project, where it came from, and under what licence.

## Summary

**No third-party art, audio or code assets are used.** Nothing was downloaded,
purchased, licensed or imported. There are no Asset Store packages, no free
model packs, no HDRIs, no texture libraries, no fonts beyond Unity's own
built-in one, and no assets of unclear ownership.

Everything visible in the shed is either generated by editor code in this
repository or is a Unity package obtained through Unity's own package manager.

This is a deliberate constraint, not an accident of circumstance. It means the
project has no licence obligations to track, nothing to re-verify before
release, and no dependency that could be withdrawn.

## 3. Placeholder assets

Marked clearly, as required. None of the following should be described as
finished production art.

| Asset | Status | What "finished" would mean |
| --- | --- | --- |
| **All 30 generated texture maps** | **Placeholder-quality** | They are procedural approximations of timber, steel and fabric, not scanned or hand-painted material. They give correct roughness behaviour, correct physical scale and plausible variation - enough to judge the room's lighting, composition and scale. A shipping product would replace them with authored or scanned PBR sets |
| **Audio** | **Absent** | `Assets/Game/Audio/` is empty. There is no ambience, no footsteps, no room tone. Out of scope for this milestone |
| **Prefabs** | **Absent** | `Assets/Game/Prefabs/` is empty. Reuse is handled by `PropLibrary` methods appending into a shared mesh, which is better for draw calls but means there are no prefab assets to point at. If hand editing becomes the workflow, this should change |
| **`ProjectVersion.txt` = 6000.0.58f1** | **Unverified** | Written without a Unity install available to confirm the exact patch release. Any Unity 6000.0.x will open the project, with an upgrade prompt if the patch differs |
| **HDRP asset** | **Defaults** | `ShedRoom_HDRPAsset` is created with HDRP's default `RenderPipelineSettings`. Not tuned for this scene's needs |

### What is *not* a placeholder

The geometry, the material roughness values, the framing, the dimensions, the
lighting rig, the controller and the layout are all authored to production
intent. If they need to change it will be because a review found a problem, not
because they were stand-ins.
